# Vola Chain Node Releases

## v0.2.0-dev (dev202504)

This release contains changes from v0.1.1-dev to v0.2.0-dev

- Updated file upload commitment challenge
- Aggregation storage backend info (currently IPFS)
- Aggregation Commitment Transaction

- Random file id generation during upload transaction
- Bug fixes
